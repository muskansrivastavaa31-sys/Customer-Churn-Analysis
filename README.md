# 📊 Customer Churn Analysis

## 🧩 Problem Statement
A company is experiencing customer churn and wants to understand why customers are leaving.

## 🎯 Objective
To analyze customer data using Python and Power BI to identify key factors affecting churn and provide actionable business insights.

## 🛠 Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Power BI
- Jupyter Notebook

## 📂 Dataset
The dataset contains customer details such as gender, tenure, contract type, payment method, monthly charges, and churn status.

## 📊 Analysis Performed
- Data cleaning and preprocessing  
- Exploratory Data Analysis (EDA)  
- Churn analysis by contract, payment method, tenure, and demographics  
- Data visualization using charts and dashboard  

## 🔍 Key Insights
- Month-to-month contracts have the highest churn  
- Electronic check users churn more  
- Tenure and monthly charges have limited impact  

## 🚀 Business Recommendations
- Promote long-term contracts  
- Improve payment experience  
- Focus on customer retention strategies
